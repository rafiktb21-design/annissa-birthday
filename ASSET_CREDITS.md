## 2. Audio & Sound Engine
- **Procedural Romantic Piano Engine & SFX (`src/utils/audio.ts`)**:
  - Synthesized via Web Audio API (warm triangle/sine harmonics with exponential release).
  - Sound effects: Wax seal snap, candle blow noise buffer, magical sparkle shimmer.
  - Audio file: `public/assets/audio/music/romantic-piano.ogg` (Pixabay license / Royalty Free).
  - Autoplay behavior: Requires explicit user interaction ("Buka Undangan" button) adhering to mobile browser policies.
